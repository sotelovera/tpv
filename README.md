# Plugin TPV para WordPress

[**Descargar el ZIP instalable: cep-tpv-8.2.0.zip**](https://github.com/sotelovera/tpv/raw/refs/heads/main/descargas/cep-tpv-8.2.0.zip)

Si GitHub pide iniciar sesión, entra con la cuenta que tiene acceso a este repositorio.

1. Descarga el ZIP enlazado arriba sin descomprimirlo.
2. Respalda tu sitio y desactiva el TPV anterior.
3. En WordPress entra en **Plugins → Añadir plugin → Subir plugin** y selecciona ese ZIP.

Usa el ZIP de la carpeta `descargas`; el botón general «Download ZIP» de GitHub descarga el repositorio y no es el paquete preparado para instalar.

Versión para evaluación, con 86 comprobaciones funcionales aprobadas. No certificada para producción; las funciones pendientes y los periféricos sin validar se detallan en [el informe](cep-tpv/docs/INFORME.md). El [manual](cep-tpv/docs/MANUAL.md) está incluido también dentro del plugin.
